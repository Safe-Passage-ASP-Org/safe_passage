WHAT IS THIS APP? (Understand this first)
------------------------------------------
Imagine you're logging into your school email on a computer.
Instead of typing a code from a text message, your PHONE pops up
and says "Hey, is this you trying to log in?"
You tap APPROVE, and the login instantly goes through.

That's exactly what Safe Passage does.
It's a security app — like Microsoft Authenticator or Google Authenticator
— but WE built it from scratch.

Think of it in 3 parts:
  1. The PHONE APP (what users use to approve logins)
  2. The WEB ADMIN PANEL (what IT admins use to manage everything)
  3. The BACKEND SERVER (the brain that connects everything)

For this demo, you are showing Part 1 — THE PHONE APP.

STEP 1 — INTRODUCE THE APP (Just talk, nothing to show yet)
-----------------------------------------------------------

SAY THIS:
  "Our app is called Safe Passage. It is a mobile security platform
   that handles MFA — which stands for Multi-Factor Authentication.

   The problem it solves is simple: passwords alone are not safe enough.
   If someone steals your password, they can still log in as you.

   Every login attempt sends a notification to your phone, and you must

IF SOMETHING BREAKS DURING DEMO — STAY CALM
===========================================================

PROBLEM: App shows an error on login
FIX: Make sure the backend PowerShell window is still open and
     shows "Now listening on: http://localhost:5143"
     If it closed, open a new PowerShell and run:
     cd c:\Users\Delta\safe_passage\backend
     dotnet run

PROBLEM: QR code stopped working / app disconnected
FIX: Open a new PowerShell and run:
     cd c:\Users\Delta\safe_passage\mobile
     npx expo start --tunnel
     Scan the new QR code

PROBLEM: Devices or Activity screen shows empty or error
SAY: "The screen is attempting to fetch live data from the backend.
      In the completed version, real data will populate here.
      The loading and error states you see now show that the API
      integration layer is in place and working."
