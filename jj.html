Prompt 3.2: Authentication & OOB MFA Flow API

Continuing with the ASP.NET Core API, implement the core Device-Based Access & Authentication Flow. Create an `AuthController` with the following endpoints: 1. `POST /api/auth/login`: Accepts Username and Password. Validates credentials. If valid, generates an `MfaSession`, triggers a Push Notification to the user's registered mobile device (simulate this using a mock NotificationService), and returns a "Pending MFA" response with the SessionToken. 2. `POST /api/auth/mfa/approve`: Called by the Mobile App. Accepts the SessionToken and cryptographically signed approval (simulate with a boolean for now). Once approved, it returns the final JWT Bearer token granting access. Provide the AuthController.cs, the JWT Token Generation logic, and the mock NotificationService. Ensure you log activities to the ActivityLog table.
